🛟 If Something Goes Wrong

  • The console window opens and closes immediately. Try moving the file into a simple folder such as C:\CLIProxyAPI before double-clicking it. Folders with unusual characters or very long paths can cause this.
  • The dashboard page will not load. Make sure the console window is still open. Then copy the address exactly as it is printed, including the port number at the end.
  • The address seems to be in use. Something else on your computer may already be using that port. Close the program, then start it again — it will pick a free port and print the new address.
  • Replies feel slow. Check your internet connection first. Streaming endpoints deliver text as it is generated, so a reply may look partial for a moment before finishing.
  • A service will not connect. Open the dashboard and reconnect that service. Sometimes sign-in sessions expire and simply need refreshing.
